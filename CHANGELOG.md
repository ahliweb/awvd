### Diubah

- Renderer (`scripts/render.mjs`): semua permintaan jaringan selain `file:`, `data:`, `about:`, dan `blob:` (HTTP, HTTPS, WebSocket, `fetch`, `sendBeacon`) kini diblokir secara bawaan lewat `context.route` dan `routeWebSocket`; render gagal dengan kode keluar `3` beserta daftar URL yang diblokir, dan keluaran `.mp4` setengah jadi dihapus. Flag baru `--izinkan-jaringan` (mati bawaan, dengan peringatan) mematikan pemblokiran; komposisi yang dibuka lewat `http(s)://` hanya boleh meminta asalnya sendiri. Memengaruhi repo proyek: komposisi yang memuat font web, CDN, atau gambar jarak jauh kini gagal (unduh sebagai aset lokal atau pakai `--izinkan-jaringan` untuk pratinjau).
- Renderer: setiap `@font-face` dimuat eksplisit (`FontFace.load()` untuk semua `document.fonts`) sebelum frame pertama, bukan hanya menunggu `document.fonts.ready`, yang tidak memuat face yang belum dipakai DOM awal (elemen berfont yang dibuat di `render()` bisa diukur dengan font cadangan; terukur 87 px lawan 120 px pada fixture uji). `@font-face` yang gagal dimuat menggagalkan render (kode keluar `1`, pesan `font gagal dimuat: ...`) alih-alih memakai font cadangan diam-diam, dan face yang baru ditambahkan di dalam `render()` dimuat sebelum tangkapan. Memengaruhi repo proyek: frame yang sebelumnya tertangkap dengan font cadangan kini memakai font yang benar, sehingga keluaran visual bisa berubah (render ulang video yang terdampak); `window.video` dan `renderFrame` tidak berubah.
- Dokumen: README `v2.1.0`, AGENTS.md `v1.6.0`, dan dokumen `docs/` yang berubah naik versi; indeks `docs/README.md` mendaftarkan `aset.md`.
- Dokumentasi tidak lagi menyebut nama, path, atau tautan repo pedoman internal AhliWeb yang privat.
- Struktur dokumentasi: isi rinci README dipindah ke folder `docs/` (arsitektur, API runtime, CLI, pemeriksaan mutu, konsep, SOP, video tertanam dan audio, aksesibilitas, batasan, lisensi, pedoman produksi, log keputusan, dan indeks); README menjadi ringkasan dengan indeks dokumentasi (README v2.0.0, AGENTS.md v1.5.0). Tidak ada perubahan kode.
- Klasifikasi repo ditetapkan dan pengaturan GitHub (proteksi `main`, check wajib, merge commit saja) didokumentasikan.
- awvd ditetapkan hanya sebagai upstream (renderer, runtime, template contoh generik, uji), bukan repo proyek video. Pemakaian di repo proyek (dependensi git terkunci SHA, struktur repo proyek, naik versi, lisensi) didokumentasikan di README §Peran repo: upstream, dengan aturan 11 di AGENTS.md dan checklist baru di template PR. Tidak ada perubahan kode.

- Renderer: encode video kini mengonversi RGB ke YUV 4:2:0 BT.709 rentang TV secara eksplisit dan menandai metadata warna SDR BT.709; profil H.264 High, B-frame 2, GOP tertutup sepanjang setengah fps. Audio `--audio` kini AAC-LC 48 kHz stereo 384 kbps (sebelumnya 192k) dan dinormalisasi secara bawaan. Mengikuti YouTube Help "Recommended upload encoding settings", EBU R 128, dan AES TD1004/TD1008. Memengaruhi repo proyek: warna dan audio hasil render berubah (render ulang video yang terdampak; level audio bawaan kini -16 LUFS, gunakan `--kenyaringan mati` untuk perilaku lama).
